# SAP Developer Challenges

Welcome to the SAP Developer Challenges repository! This repository contains various hands-on coding challenges and projects from the SAP Developer Advocates team and the SAP Community.

## Overview

The purpose of this repository is to track progress, store code, and document learning from various SAP Developer Challenges. Each challenge is self-contained within its own directory.

## Challenges Directory

* [July 2026 - Snake & Ladder with SAP CAP Status Transition Flows](./07-July-2025/README.md): A 4-week challenge to build a multiplayer Snake & Ladder game backend using SAP CAP and its `@flow.status` feature.
